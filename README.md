
# Retail Sales Analysis

## Project Overview

This project focuses on analyzing retail sales data to understand sales, profit, customers, products, and business performance.

The dashboard was created in Power BI using KPI cards, charts, filters, and DAX measures.

## Objectives

- Analyze sales and profit
- Understand customers and orders
- Identify top products and categories
- Analyze monthly sales trends
- Compare locations and payment methods

## Tools & Technologies

- Power BI
- DAX
- Excel
- Data Cleaning
- Data Visualization

- Total Sales

## Business Recommendations

- Focus on high-performing products and categories.
- Review low-profit products.
- Target valuable customers with suitable offers.
- Optimize discounts to maintain profit.
- Focus on better-performing locations.
- Use monthly trends for future planning.
